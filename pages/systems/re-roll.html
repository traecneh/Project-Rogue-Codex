Reforge

Eligibility

Epic+

The current client describes Reforge as an action for Epic-or-higher equipment.

Currency

Rarity Shards

Rare, Epic, Mythical, and Ascendant Reroll Shards form the current shard family.

Menu

Tinker Tools

Open Tinker Tools, choose Reforge, then select the equipment you want to reforge.

Outcome

Fresh Stat Spread

Stats are rerolled within the item's current rarity tier.

What Changes

Changes

A new Strength, Dexterity, and Constitution spread. Total stats can vary within the current rarity range.

What Does Not Change

Item identity, Current Rarity, Max Rarity, base values, and sources.

Reforging replaces the current stat roll; a better result is not guaranteed.
